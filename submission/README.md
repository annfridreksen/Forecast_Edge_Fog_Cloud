## Статья
`submission.zip` содержит `main.tex`, подключаемые исходники, класс/нестандартные стили, чистый PDF, описание источников и скрипт. Все схемы построены TikZ; отдельных растровых рисунков статьи нет. `.bib/.bbl` не используются: список задаётся включаемым `r15-references.tex`. Файлы шрифтов не распространяются.

Сборка после распаковки **в новую папку**:

```sh
sh build.sh
```

Нужны pdflatex, пакеты TeX Live: latex-extra, lang-cyrillic, fonts-recommended, cm-super. Установленные версии и строки класса фиксируются журналом сборки и `style-provenance.json`. Факт загрузки официального класса, хеш и `ProvidesClass` указаны отдельно; неудача сети не считается подтверждением последней версии.

`article.pdf` — чистая редакция. `before_R14.pdf` — точный ранее предъявленный PDF SHA256 `2c24e693106be38e9e56de8ff33610b7a45eab1e10905dfac3d0a0be2b41e920`. `difference.pdf` — отдельное сравнение; точная процедура и возможный отказ latexdiff отражаются в `difference-provenance.json`, не скрываются. Базовый исходный SHA `59914cea5dc733ec857ae3d4157d77398bae7cd5`. Текущий исходный SHA — в `build-receipt.json`.

## Данные и воспроизводимость
Числа статьи заморожены на **131 запросе**, научный run45174257711, архив14820151165; это не последний накопленный кэш162. Первая main-серия: Fog30/B5/rho50=.10, seed0–9. Нулевые потери не удостоверяют риск≤0,1%; совместный статус `INSUFFICIENT_DATA` не изменён.

Полный исходный ZIP этого среза разбит на части `frozen131.zip.part00` и далее, каждая менее100МиБ. В `data-parts.json` записаны все размеры/хеши и хеш восстановленного ZIP. Части содержат **не новые опыты**, а точные уже сохранённые первичные данные. Соберите их локально:

```sh
python reassemble.py --directory /path/to/downloaded/parts --output frozen131.zip
```

Для скачивания без авторизации из одной версии репозитория добавьте `--revision COMMIT_SHA`, где SHA принадлежит опубликованному комплекту в `night/fefc-v3`. Скрипт проверяет каждый файл и весь архив. `SHA256.json` фиксирует хеши остальных материалов. URL каждого реально проверенного анонимного скачивания и commit публикации находятся в журнале Actions/реестре публикации.

`reproducibility.zip` содержит исходники вычислительной модели, проверок и блокнотов; прогнозные исторические модули не вызываются текущим исследованием. После распаковки программы и архива данных:

```sh
python -m pip install -r requirements.txt
python scripts/check_r15_paper.py --checkpoint /absolute/path/to/frozen131 --out /tmp/r15-number-check
```

Эта команда **читает** когорты и проверяет вывод блокнота, не запускает научную имитацию или bootstrap. Программное выполнение nbconvert не равно проверке личного браузера Colab. Контрольная точка продолжения полной научной карты описывается отдельным `docs/STATUS.md` репозитория; не использовать архив статьи для незаметного отката научного прогресса.
