# Forecast_Edge_Fog_Cloud

Проверяемое прогнозное размещение целых подграфов в краевых и туманных средах (НИР 00-26-04). Все данные синтетические; нейросеть не испытывалась.

- `v2/` — эталонная версия BT26 v2 (код 0.2.0, 98 тестов, результаты, статья v2). Не изменять.
- `docs/TASK.md` — задание на сборку проекта v3 (код, визуализация в Colab, статья).
- `docs/STATUS.md` — текущее состояние работы.

Запуск эталона: `cd v2/code && python -m unittest discover -s tests -v`.
