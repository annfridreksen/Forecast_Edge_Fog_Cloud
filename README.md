## Начать без программирования
Откройте [00_Старт в Colab](https://colab.research.google.com/github/annfridreksen/Forecast_Edge_Fog_Cloud/blob/night/fefc-v3/colab/clean/00_%D0%A1%D1%82%D0%B0%D1%80%D1%82.ipynb) и выберите «Среда выполнения → Выполнить всё».
Тетрадь получает рабочую ветку, устанавливает зависимости в Colab, запускает тесты и показывает схемы среды/нейросетевого интерфейса, p95 и потери против ρ, составляющие задержки, прогноз против факта и таблицу «утверждение → файл → ячейка».
По умолчанию читаются сохранённые результаты: большие серии и обучение не повторяются. Все проверки срабатывают по данным, а не печатают безусловное OK.

## Запустить модель или проверки локально
```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
(cd v2/code && python -m unittest discover -s tests -v)
python -c "from efc import simulate; print(simulate()['metrics'])"
python scripts/start_dashboard.py
python -m jupyter nbconvert --to notebook --execute colab/clean/00_Старт.ipynb --output-dir colab
```
Для новых вычислительных экспериментов открывайте 01→02→03: 01 создаёт среду и серии, 02 обучает демонстрационную сеть на train и калибрует на calibration, 03 вызывает неизменённый эталон v2. Новые численные результаты нельзя смешивать со старой статьёй без пересборки и реестра происхождения.

Полная пересборка всех серий требует LaTeX и явного решения повторить расчёты:
```sh
python scripts/build_artifacts.py
python scripts/start_dashboard.py
python -m jupyter nbconvert --to notebook --execute colab/clean/00_Старт.ipynb --output-dir colab
```
`build_artifacts.py` удаляет и создаёт заново генерируемые `results/`, `colab/`, `article/figures/`: не храните там единственные копии своих правок. Адресный CI текущего этапа использует `scripts/check_cached_artifacts.py` и отказывается считать старые серии действительными при изменении научного кода.

## Границы
Запуск проверяется через nbconvert в Actions; личный веб-интерфейс Colab непосредственно не запускался. Время чужого runtime не гарантируется. Нулевые потери серии не означают нулевую вероятность потери, p95 не является гарантированным сроком. Калибровка MLP не достигла 95% покрытия. P может быть медленнее B: прогнозный вектор имеет приоритет. Нет заявлений о промышленной точности или универсальном преимуществе прогноза.

Три источника R19 включены с DOI и объяснением связи; вместе с остальным обзором 14 DOI-записей и предоставленные тезисы НСКФ (URL программы не выдаётся за полный текст тезисов). Авторские сведения и выходные данные сборника остаются предметом научного согласования.
