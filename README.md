# Forecast_Edge_Fog_Cloud — v3

Ветка `night/fefc-v3`: новая дискретно-событийная модель Edge–Fog–Cloud, прогнозная «розетка» с демонстрационной нейросетью и краткая проверка выбора целых подграфов. Все новые данные синтетические. Промышленная точность сети и универсальное преимущество прогноза не заявляются.

- [Модель простыми словами](docs/Модель_простыми_словами.md).

- [Происхождение чисел](docs/Утверждения.md), [ответ R1–R19](docs/Ответ_на_замечания.md).

`v2/` — неизменяемый эталон BT26 (код 0.2.0, 98 тестов). В v3 он импортируется без правок. Прежнее утверждение «нейросеть не испытывалась» относится к эталону v2; новая v3 содержит отдельную демонстрационную сеть, обученную только на данных новой модели.

`docs/TASK.md` — задание, `docs/STATUS.md` — состояние. Все изменения находятся в рабочей ветке; main не изменяется. Старая модель 2025 не использовалась.

## Проверка
```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
(cd v2/code && python -m unittest discover -s tests -v)
```
Полная сборка из чистого checkout с установленным LaTeX: `python scripts/build_artifacts.py`. Она заново создаёт генерируемые `results/`, `colab/`, `article/figures/`. Не храните там единственные копии своих правок.

В GitHub Actions выполняются реальные тесты и nbconvert; непосредственный веб-интерфейс Google Colab не проверялся. Наличие выполненных тетрадей не гарантирует скорость другого runtime. PDF и результаты появляются после успешного workflow; его код выхода и журналы являются основанием статуса.
