При чтении ветки 21.11.2026 HEAD указывает на указанную базовую версию.
В этом шаге удалённая ветка не изменялась. Исправленная версия 0.2.0 находится
в данном архиве; точный состав определён MANIFEST.sha256 и environment.json.
Не ссылаться на базовый коммит как на исправленную версию.

В review/revision_v2.patch включены только Python-код, тесты, программы серий
и pyproject.toml. Исходные Git blob-хеши десяти старых Python-файлов сверены
с ранее проверенными файлами базового коммита. git apply --check и побайтовая
сверка после применения прошли на отдельной копии. Сведения о проверке:
review/patch_verification.json. README, статья, документация и результаты
переданы отдельными файлами архива и в patch не входят.

Техническое применение из корня репозитория на чистой базовой версии:
```
git switch research/bt26-ordinal-placement-2026-11-21
git apply --check /путь/к/revision_v2.patch
git apply /путь/к/revision_v2.patch
```
После применения необходимо повторить тесты и обе программы серий. В этом шаге
не выполнены удалённая публикация, коммит исправлений или слияние с main.
Пользователю не требуется применять patch для передачи на рецензию:
рецензенту достаточно четырёх новых файлов v2.
