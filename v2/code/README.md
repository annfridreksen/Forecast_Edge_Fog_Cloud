## Запуск из каталога code
Нужен Python 3.10+ по синтаксису. Фактическая среда и SHA-256 указаны в
results/environment.json. Ядро и тесты используют стандартную библиотеку.

```sh
python -m unittest discover -s tests -v
python -m bt26 examples/minimal.json --forecast examples/forecast.json --method P --deterministic-output --output results_reproduced/minimal_P.json
python -m bt26 examples/minimal.json --forecast examples/forecast.json --method B --deterministic-output --output results_reproduced/minimal_B.json
python -m bt26 examples/no_feasible.json --forecast examples/forecast.json
python run_study.py --seeds 60 --out results_reproduced
python run_review_checks.py --seeds 80 --permutation-seeds 60 --out results_reproduced/review_checks
```
CLI возвращает 0 при найденном плане, 2 при отсутствии выданного плана
(проверяйте точный статус), 3 при ошибочном входе. Ошибка дифференциальной проверки
run_study завершает процесс ненулевым кодом только после сохранения результатов.
Файлы minimal_P.json и minimal_B.json также автоматически создаёт run_study.
--deterministic-output удаляет измерения времени, но сохраняет планы и счётчики.
Без этого флага побайтовое совпадение временных журналов не ожидается.

## Состав
model.py — граф, разбиение, ресурсы и применимость внешних команд.
scheduler.py — детерминированный построитель расписания.
verify.py — проверка без вызова построителя; агрегаты пересчитаны из source.
search.py — P/B/D, экспорт границы, аудит очереди и повторный выбор.
replay.py — проигрывание сохранённых назначений/маршрутов на скрытых календарях.
run_study.py — повтор основной серии без изменения численных входов v1.
run_review_checks.py — активные сроки, покрытие очереди, тест кода границы,
шесть перестановок имён устройств. tests/test_review.py — адресные регрессии.

## Проверки
98 автоматических тестов прошли. В исходной серии — 59 действующих прогнозных
запусков из 60 запросов P: seed 20 переходит в B из-за постоянных команд.
Среднее число проверок — 6,8 по 60 запросам, 5,593220338983051 по 59 прогнозным;
78 — полный перебор допустимых по памяти назначений, не сильный конкурентный
планировщик. B/D используют общие ключ, построитель и проверку с эталоном.
Совпадения не являются независимой валидацией физической модели.

Дополнительные сроки 60/30/35 мс: 80/80 совпадений на каждый срок. На 30 мс
10 случаев без плана в классе построителя; отвергнутые планы не исключены из отчёта.
240 проверок покрытия очереди и 31 995 пар граница/продолжение без расхождений.
Досрочные P и D чувствительны к именам устройств; соответствующий CSV сохранён.
Средний план P=29,2416667 мс, B=24,34 мс: различие возникает уже при планировании.
Полезность настоящей нейросети, промышленные гарантии и глобальный оптимум
по всем расписаниям не установлены.

## Ограничения
Резервирование памяти на весь расчёт, целые непрерываемые блоки, фиксированное
разбиение и конкретная политика расписания. Нет живой миграции, переразбиения,
конечного потока очередей или служебного подтверждения реальных ресурсов.
