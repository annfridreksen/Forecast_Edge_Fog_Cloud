Новая точка входа — `scripts/r15_package_corrections.py`, использующая ранее сохранённые функции упаковки. Ошибка TeX теперь печатает точный хвост в job-log, а не только локальный путь. Рабочие выходы/исходные файлы защищены. Старый entry point сохранён для истории, workflow его main больше не вызывает. Реальный результат исправления устанавливается только последующим Actions; до его завершения PDF/ZIP не названы собранными.
