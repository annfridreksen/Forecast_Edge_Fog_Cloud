# Issue #4, пункт 12

В тетрадь00 добавлены схема среды, движение рассчитанного события и финальная таблица с независимой сверкой базовых/контрольных чисел. Четыре тетради добавляют записи в единый results/claims.json через efc/claims.py. Каждая запись содержит файл первичных данных, поле/селектор, значение и тетрадь; несовпадение или изменение источника вызывает ошибку. Итоговый builder проверяет наличие вкладов всех00–03 и сохраняет прежний подробный реестр статьи отдельно как article-claims.json.

В01 включена серия180стационарных прогонов и контроль прогрева; её графики строятся только вызовом из тетради. Код00/схемы/анимация/claims реально исполняются nbconvert в новом runner; статус не считается подтверждённым только наличием исходного ipynb. Перед этим локально пройдены49новых тестов.
