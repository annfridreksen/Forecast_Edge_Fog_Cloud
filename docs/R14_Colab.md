# Основной экран R1.4

Открыть `colab/00_Старт.ipynb` из ветки `night/fefc-v3`, выполнить сверху вниз. В чистом Google Colab тетрадь получает эту ветку и зависимости; существующая копия не обновляется молча. Фактический SHA выводится первой ячейкой. Для воспроизводимости сначала получите нужный коммит репозитория, затем запускайте находящуюся в нём тетрадь. Точный проверенный коммит записывается в STATUS/Actions, а не предполагается по имени ветки.

Три настройки: общий поток λ, число Fog и буфер B. Кнопка «Рассчитать и проверить» запускает 600 синтетических сообщений одним действующим событийным ядром, seed42. Списки сами ничего не рассчитывают. Полная сетка, bootstrap и прогнозы автоматически не запускаются. В основной среде1000 датчиков/40 Cloud; ручные примеры с1 Fog выделены отдельно.

## Три разных результата
1. **Сейчас выполнен короткий опыт:** p95 завершённых, потери по всем созданным, H(t), шесть составляющих и очередь. Нет прогрева/10 seed/ДИ, нет заявления о статистической допустимости.
2. **Сохранённая статистика:** переменная среды `FEFC_CHECKPOINT` указывает на извлечённый неизменный артефакт; по умолчанию `results/r14/night-map`. Проверяются manifest, config_id, хеш main и frozen pilot; готовая оценка и95% ДИ читаются, не пересчитываются. Первоисточник полного результата остаётся архивом Actions; интерфейс не повторяет его полный первичный аудит при каждом клике. Отсутствующая клетка — «не рассчитано», не ноль. Графики p95/потерь от rho50 строятся только по имеющимся итоговым оценкам; промежутки не соединяются.
3. **Ручное отключение датчика:** отдельная иллюстрация. Команда в3мс предшествует генерации на равенстве; уже созданные ID0,1,2,4 сохраняются; ID3,5 не создаются и не считаются потерями Fog. Внутренние плотные номера ядра явно сопоставлены исходным номерам. Основная карта не изменяется.

Ручной пример5 сообщений содержит таблицу буквальных ответов и временную диаграмму всех6 составляющих. Отдельная таблица связывает проверяемые утверждения, ID ячеек и первичные файлы; неподтверждённые карта/минимум не выдаются за результат.

## Проверка
`python -m unittest discover -s tests -p test_dashboard.py -v`

`python scripts/check_r14_dashboard.py`

Вторая команда выполняет реальную стартовую тетрадь через nbconvert, проверяет6 выполненных кодовых ячеек, явный единственный демонстрационный запуск, обработчик отключения, отсутствие скрытой сетки/прогноза и минимум2 изображения. Первая проверяет реальные объекты ipywidgets/клики и ошибки, а не заменяет их тестовой заглушкой. Полный historical unittest этим маршрутом не объявляется зелёным.

**Ограничение:** nbconvert и программный вызов `.click()` не проверяют мышь/виджетный front-end в личном браузере Colab. Научная сетка пока не закончена; интерфейс не превращает отсутствие результатов в числа. Старые тетради01/02/03 этим пунктом не переписаны и не приняты как R1.4.
