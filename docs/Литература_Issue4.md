# Issue #4, пункты 10–11

Добавлен реестр 18 DOI: исходные fog/edge, HEFT, обзор размещения, iFogSim/iFogSim2, EdgeCloudSim/YAFS, Wang/FogBrain, прогноз задержек V2X и потоковых задач, метрики точности, конформная калибровка, Kendall/Little. Библиография генерируется из подтверждённых регистрационных метаданных; каждое цитируемое DOI проверяется на совпадение идентификатора и названия, иначе сборка завершается ошибкой. Карточка регистрации не равна полной экспертизе статьи.

Источник НСКФ включён отдельно: Игнатенко А. С., Орда-Жигулина М. В., «Исследование конфигурации вычислительной среды Edge-Fog», 2026; выходные сведения уточняются. DOI ему не выдуман. Русский авторский блок предоставленных тезисов использован без переноса противоречивого английского блока.

Wei 10.4230/LIPIcs.APPROX/RANDOM.2020.60 существует: прежний код уже применял quote(safe=''), поэтому одна замена кодирования не устраняла бы проблему. Добавлен DataCite наряду с Crossref. Временная недоступность не превращается в ok=true.

Раздел доступности кода указывает репозиторий, ветку и фактический исходный коммит runner; последующий коммит generated output фиксируется в PR. main/v2/журнал проверяющего не изменяются.
