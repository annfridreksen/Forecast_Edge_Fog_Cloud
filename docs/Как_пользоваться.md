Выполните только добавленную ячейку. Для каждой новой среды выполнения 00–03 эту операцию повторяют. Она скачивает точный коммит и устанавливает зависимости; моделирование не запускает.

```python
from pathlib import Path
import os, subprocess, sys
EXPECTED_SHA = "c20aaa889337d23e2ab34033fe735ee5e0e905f9"
URL = "https://github.com/annfridreksen/Forecast_Edge_Fog_Cloud.git"
root = Path("/content/fefc-pinned-" + EXPECTED_SHA[:12])
if root.exists():
    raise RuntimeError("Каталог уже существует. Для чистой проверки начните новый сеанс Colab; старые файлы не удаляйте.")
root.mkdir()
subprocess.run(["git", "init", str(root)], check=True)
subprocess.run(["git", "-C", str(root), "remote", "add", "origin", URL], check=True)
subprocess.run(["git", "-C", str(root), "fetch", "--depth=1", "origin", EXPECTED_SHA], check=True)
subprocess.run(["git", "-C", str(root), "checkout", "--detach", "FETCH_HEAD"], check=True)
actual = subprocess.check_output(["git", "-C", str(root), "rev-parse", "HEAD"], text=True).strip()
if actual != EXPECTED_SHA or subprocess.check_output(["git", "-C", str(root), "status", "--porcelain"], text=True).strip():
    raise RuntimeError("Не подтверждена чистая контрольная копия. Остановитесь.")
os.chdir(root)
subprocess.run([sys.executable, "-m", "pip", "install", "-q", "-r", "requirements.txt"], check=True)
print("Контрольный SHA:", actual)
```

Теперь выполните только штатную ячейку setup (`r14-main-setup` в 00, `r14-01-setup` в 01 и аналогично в 02/03). Она найдёт закреплённую локальную копию по текущему каталогу, не будет клонировать ветку и напечатает `Источник:`. Сверьте полный `SOURCE_SHA` с `EXPECTED_SHA`. При несовпадении, ошибке установки или перезапуске среды не переходите к следующим ячейкам. Используйте новый чистый сеанс; не подменяйте SHA переменной окружения.

Затем в 00 выполните только ячейку `r14-main-schema` (`architecture_figure`) — это схема пути сообщения. `r14-main-panel` запускает 600 сообщений (seed 42, без прогрева); `r14-main-manual` и `r14-main-shutdown-check` — отдельные демонстрации. Для чтения готовой статьи эти три опыта пропустите. Не выбирайте «Выполнить всё» для просмотра одной схемы.

Хеш сравнивается с [реестром научного среза](https://github.com/annfridreksen/Forecast_Edge_Fog_Cloud/blob/c20aaa889337d23e2ab34033fe735ee5e0e905f9/deliverables/r15-visual-final/empirical-evidence.json).

```python
from pathlib import Path
from zipfile import ZipFile
import hashlib, os
archive = Path("/content/r14-map-45174257711.zip")  # фактический путь
expected = "2cb91dbc964a641c36fb53e02ddea3590bf8fe939933f43b31399267508d40ef"
with archive.open('rb') as f:
    actual = hashlib.file_digest(f, 'sha256').hexdigest()
if actual != expected:
    raise RuntimeError("SHA256 архива не совпал с реестром статьи.")
dest = Path("/content/fefc-article-map-45174257711")
if dest.exists():
    raise RuntimeError("Каталог уже существует; выберите новый пустой каталог.")
dest.mkdir()
with ZipFile(archive) as z:
    z.extractall(dest)
candidates = [p.parent for p in dest.rglob('map.json')
              if (p.parent / 'manifest.json').is_file()
              and (p.parent / 'cells/r0.10_F30_B005/main.json').is_file()]
if len(candidates) != 1:
    raise RuntimeError("Не найден единственный корень научного архива.")
os.environ["FEFC_CHECKPOINT"] = str(candidates[0])
print("Источник данных:", os.environ["FEFC_CHECKPOINT"])
```

Выполните `r14-01-load`; ожидается `CHECKED_CHAINS`, а не `NO_CHECKPOINT` или `ARCHIVE_UNVERIFIED`. Сверьте напечатанные канонические хеши manifest и map с `empirical-evidence.json`. При несовпадении остановитесь. Ячейку карты `r14-01-map` можно просмотреть по желанию. В `r14-01-curves` задайте `FOG = 30` и `BUFFER = 5`; затем в `r14-01-summary` задайте `SUMMARY_KEY = "r0.10_F30_B005"`. Выполните обе ячейки. Сверьте выбранный ключ, путь `cells/r0.10_F30_B005/main.json`, байтовый и канонический хеши с реестром. Здесь 131 первичный запрос (пилоты и итоговые реализации), не 131 конфигурация. Статус выбранной клетки `r0.10_F30_B005` — `INSUFFICIENT_DATA` из-за вырожденного интервала при нуле потерь не заменять вручную: в статье приведена отдельная условная оценка потерь при допущении независимости. Это не доказанный глобальный минимум.

## 5. Что проверено и чего не делать

Инструкция сверена статически с четырьмя блокнотами контрольного коммита и реестром статьи. Новый личный запуск в браузере Colab, загрузка ZIP и фактическое выполнение приведённых ячеек в этом ходе не проверены. Если ошибка — сохраните текст ошибки, SHA кода и название ячейки. Никаких новых научных серий, обучения или полной сборки статьи для авторской проверки не требуется.

Исторические `colab/clean/`, `article/main.pdf`, демонстрационное обучение и `scripts/build_artifacts.py` не являются текущим маршрутом. [Прежняя инструкция](https://github.com/annfridreksen/Forecast_Edge_Fog_Cloud/blob/c20aaa889337d23e2ab34033fe735ee5e0e905f9/docs/%D0%9A%D0%B0%D0%BA_%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%D1%81%D1%8F.md) сохранена в контрольном срезе; не выполнять её как руководство R1.5.
