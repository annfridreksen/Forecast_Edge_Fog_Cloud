# R1.2 — 3. Совместная допустимость и метрики

Когорта — все внешние поступления в фиксированном измерительном окне. D — время от генерации до окончания Cloud. Q — p95 распределения D условно по завершённым событиям; L — потери/все поступившие. Потерянному событию не присваивается нулевая задержка. Незавершённые на контрольной границе сохраняются отдельным исходом; оценка не признаётся окончательной, пока судьба принятых событий не установлена.

Обязательный график: **H(t) = число поступивших в когорту событий, успешно завершённых с D ≤ t / число всех поступивших в когорту**. Аргумент t — задержка после собственного поступления, не календарное время опыта. Потерянные остаются в знаменателе. Предел кривой при полном дообслуживании равен 1−L. На графике отмечаются 200 мс и H(200 мс); это дополнение, а не замена двух исходных ограничений.

Точечные оценки Q и L получают по объединённой когорте десяти реализаций, сохраняя также оценки каждого seed. Доверительные интервалы (ДИ) строятся приближённым кластерным bootstrap: пересэмплируются целые независимые реализации/seed, сохраняются зависимые события внутри них, Q и L пересчитываются. Нельзя применять независимый биномиальный интервал ко всем событиям очереди. Проектный параметр: 10000 bootstrap-повторов с фиксированным seed; повторной имитации они не требуют. 95%-е интервалы для описания; для решения по двум условиям — односторонние верхние границы с номинальным уровнем 97,5% каждая (поправка Бонферрони), то есть совместный номинальный уровень не ниже 95% в пределах применимости самих интервалов. Это не точная конечновыборочная гарантия при 10 seed и не одновременная гарантия для всей карты.

Правило после контроля прогрева/точности:
- допустима: U_Q ≤ 200 мс **и** U_L ≤ 0,001;
- недопустима: соответствующая нижняя граница превышает хотя бы один порог;
- иначе: недостаточно данных. Нулевые наблюдённые потери и вырожденный интервал [0,0] не удостоверяют нулевой риск: такая клетка остаётся неопределённой по потерям до обоснованной невырожденной верхней оценки.

Выбор — лексикографический минимум (n_F,B) среди подтверждённо допустимых клеток. Если существуют лексикографически меньшие неопределённые клетки, пишется «наименьшая подтверждённая конфигурация; минимум не установлен». Пустая подтверждённая область не означает доказанного отсутствия решения, пока остаются неопределённые клетки. Выбранный кандидат проверяется отдельными десятью seed, не использованными при выборе; не заявляется семейная 95%-я гарантия всех сравнений карты.

Дополнительно: средняя задержка, конечный максимум, ожидание Fog, занятость и парные разности при одинаковом внешнем потоке. Шесть составляющих: Edge; Edge–Fog; ожидание Fog; обработка Fog; Fog–Cloud; Cloud. Ожидания включаются ровно один раз в соответствующую стадию. Доли рассчитываются для одной и той же совокупности завершённых, каналы относятся отправителю; сумма — 100% до округления. Новых численных результатов эта спецификация не содержит.
