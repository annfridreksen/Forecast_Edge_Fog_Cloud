# R1.2 — 2. Быстрый заменитель модели

Сценарий 80/4/8 и таблица Fog × train/calibration/test из прежней постановки исключаются из нового исследования. Содержательная часть возражения 2 принимается: тестовая совокупность общая, различия состава данных и утечка контролируются. Конкретная прежняя зональная диагностика больше не отвечает утверждённой автором задаче.

«Розетка»: **параметры конфигурации (λ, n_F, B; остальные профили фиксированы) → сменный оцениватель → p95 в мс, доля потерь, область применимости → проверка двух требований → кандидат конфигурации → подтверждение имитацией**. Это офлайн-аппроксимация результатов симулятора, не прогноз будущего отдельного события и не порядковые команды эталона v2/.

Обучающие цели получают только из единой сетки R1.2. Полные тройки (λ,n_F,B), со всеми их seed, делятся до просмотра выходов: 60% обучение, 20% валидация, 20% тест; фиксированная перестановка лексикографического списка, seed разбиения 20261122, список сохраняется. Ни один seed одной конфигурации не попадает в другой раздел. Предобработка — только по обучению; настройка — только по валидации; тест открывается после фиксации модели. Общие случайные потоки между конфигурациями не выдаются за независимые наблюдения. Демонстрационная нейросеть — многослойный перцептрон со слоями 16/8 и фиксированной инициализацией 42; это проектное допущение, не оптимальная архитектура.

Сравнения на тех же отложенных конфигурациях: нейросеть; приближение M/M/1/K (пуассоновские поступления, экспоненциальное обслуживание, один сервер, K=B+1); имитационный эталон с равномерным сервисом и конкуренцией каналов. Для формулы используют фактические λ_j зон и среднее обслуживание Fog 55 мс. Потери — вероятности заполнения с весами входного потока; распределение задержки Fog — условно по принятым событиям, с весами принятого потока. Для сквозной оценки распределение Fog свёртывается с заданными распределениями остальных сервисов, **не складываются p95 стадий**. Независимость стадий и отсутствие их ожиданий — явные упрощения аналитического варианта; его ошибки относительно полной среды измеряются, а не устраняются подгонкой по тесту.

Метрики: ошибка p95 в мс, ошибка потерь в процентных пунктах, случаи ложного признания конфигурации допустимой/недопустимой и ошибки выбора минимальной конфигурации. Неопределённые имитационные метки не превращаются в правильные ответы. На тесте публикуются все расхождения, в том числе где M/M/1/K точнее нейросети. Время одного запроса, обучение и подготовка имитационных данных учитываются раздельно; ускорение не обещается заранее. Нейросетевая оценка сама по себе не удостоверяет выполнение требований.

Подграфы v2/ — только неизменённый краткий пример/приложение. Адаптивная прогнозная разгрузка Fog→Cloud — дальнейшая работа; в текущем опыте её нет.
