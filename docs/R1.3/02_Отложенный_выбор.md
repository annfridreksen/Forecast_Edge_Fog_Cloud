# R1.3 — 2. Проверка выбора вне обучения

22.11.2026. ПРЕДЛОЖЕНИЕ. Основание: Issue #5, возражение 2 в комментарии 7079667595. Принято: все оцениватели выбирают только из одного отложенного набора. Заменяется разбиение и неопределённое множество выбора из R1.2/02; среда, сетка и цели не меняются.

## Разбиение фиксируется по входам, до новых результатов
Числа Fog в порядке возрастания: 30,40,50,60,70 (индекс i=0…4); буферы: 0,2,5,10,20,50,100,200,400 (индекс j=0…8). Вычисляется s=(i+2j) mod 5. При s=0 пара (n_F,B) относится к тесту, при s=1 — к валидации, остальные — к обучению. Одна пара сохраняет раздел при всех шести λ и всех seed, включая пилотные и подтверждающие данные: метки отложенных пар не используются для подгонки оценивателей. Это заменяет прежнюю случайную перестановку R1.2; правило зависит только от входной сетки, а не её метрик.

Получаются 27/9/9 пар на каждый λ, всего 162/54/54 полных конфигураций для обучения/валидации/теста. Общие девять тестовых пар для КАЖДОГО λ:
`(30,0), (30,50), (40,5), (40,200), (50,20), (60,2), (60,100), (70,10), (70,400)`.
Валидация: `(30,10), (30,400), (40,0), (40,50), (50,5), (50,200), (60,20), (70,2), (70,100)`. Остальные пары — обучение. Все пять значений числа Fog представлены в тесте. Список сохраняется как манифест разбиения до подгонки; этот текст уже фиксирует его однозначно.

## Один протокол для всех оценивателей
1. Предобработка и обучение — только обучающие конфигурации; выбор настроек — только валидация. Модели, настройки и списки кандидатов замораживаются до открытия тестовых целей. Пилотное управление длительностями имитации не даёт оценивателям доступа к тестовым меткам. В признаках только λ,n_F,B, а не результаты симулятора.
2. Для каждого λ нейросеть, табличный оцениватель и M/M/1/K вычисляют p95/потери для одних девяти тестовых пар. По собственным оценкам и исходным двум порогам выбирают лексикографически минимальную пару. Если подходящих нет — явный отказ. Имитационные метки при выборе им не передаются.
3. После фиксации прогнозов раскрывается имитационный эталон этих же девяти клеток. Публикуются все клетки, предсказания и ошибки, выбранная пара каждого метода, её имитационная метка и минимум оценённой тестовой карты. Это минимум только среди девяти кандидатов, с ограничениями пункта 1 R1.3, не минимум всей сетки.
4. Неопределённые метки учитываются отдельной категорией. Рекомендация неопределённой клетки не считается ни верным решением, ни ложной допустимостью. При отсутствии однозначного эталонного ответа ошибке выбора не назначается фиктивное нулевое значение. Сохраняются знаменатели всех долей.

Применение к полным 45 кандидатам на λ — отдельная описательная таблица, содержащая и обучающие клетки; оно не называется отложенной проверкой. Независимое подтверждение кандидата — по пункту 1 R1.3.

Общие случайные потоки между клетками создают зависимость: это проверка переноса на неизвестные конфигурации, не на независимые новые потоки. Ошибки сравниваются попарно на общих клетках, без объявления 54 клеток независимыми повторениями. У неопределённого симуляционного эталона численная ошибка тоже показывается с оговоркой о его точности. При оценке неопределённости сохраняется целый общий вектор результатов одного seed; сами 95%-е интервалы имитационных метрик остаются по R1.2. Доверительная гарантия превосходства оценивателей в этом проекте не обещается.

Контроль спецификации: непересечение и полнота разделов, 27/9/9 при каждом λ, одинаковые тестовые кандидаты у всех методов, запрет использования тестовых целей при подгонке. Новых имитационных серий для этого разбиения сверх единой сетки не вводится.
