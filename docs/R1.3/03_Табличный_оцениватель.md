# R1.3 — 3. Табличная альтернатива нейросети

22.11.2026. ПРЕДЛОЖЕНИЕ. Основание: Issue #5, возражение 3 в комментарии 7079667595. Принято: одного сравнения с упрощённым M/M/1/K недостаточно для вывода о пользе именно нейросетевого оценивателя. Дополняется R1.2/02; новых имитационных серий не требуется.

## Заранее определённый табличный прогноз
Добавляется регрессия по k ближайшим обучающим конфигурациям (kNN). Входы те же, что у многослойного перцептрона: λ, n_F, B; цели — p95 в мс и доля потерь из одной имитационной сетки. Одна строка таблицы соответствует целой обучающей конфигурации и её агрегированным метрикам, не отдельному событию/seed.

Входы стандартизуются средним и стандартным отклонением (делитель n) только по обучающим конфигурациям. Признак с нулевым отклонением не участвует в расстоянии. Расстояние евклидово; равные расстояния разрешаются лексикографическим порядком (λ,n_F,B). Для обоих выходов берётся невзвешенное среднее целей одних и тех же k соседей.

k выбирается из {1,3,5,9} только по валидационным конфигурациям: минимум суммы MAE(p95)/200 мс + MAE(потери)/0,001, при равенстве — меньшее k. Это заранее заданное равное нормирование относительно авторских порогов, не денежная функция стоимости. Выбирается один k для всей сетки; после просмотра теста он не меняется. Табличные значения, шкалы и k фиксируются до теста; валидационные цели в таблицу соседей не добавляются.

Нейросетевая архитектура 16/8 и инициализация 42 сохраняются из R1.2, а не подбираются ради выигрыша. Предобработка её входов имеет тот же контракт. При невозможности получить оценку возвращается явный отказ, а не допустимая конфигурация. Преимущество сети или необходимость её применения заранее не заявляются.

## Общая проверка
Сравниваются kNN, многослойный перцептрон и M/M/1/K: одна таблица тестовых кандидатов R1.3/02, одинаковые два требования, одинаковый лексикографический выбор. Имитация — общий оценённый эталон, не безошибочная истина.

Сохраняются для каждого оценивателя: ошибки p95 (мс) и потерь (процентные пункты); ложная допустимость и ложное исключение относительно определённых меток карты; отдельное число неопределённых клеток и отказов; выбранные n_F/B и статус по имитации; отличие от минимума оценённой тестовой карты. Доли сопровождаются точными знаменателями. Парные разности ошибок считаются на общих клетках; 54 зависимые клетки не используются как 54 независимых повторения для теста значимости. Сводки сравнений описательные; они не дают гарантии превосходства на новых потоках.

Время запроса, обучение/подготовка табличного оценивателя и нейросети, аналитический расчёт и получение имитационных меток учитываются раздельно в одной среде. Время загрузки модели не подменяет время запроса, а стоимость её обучения не скрывается. Повторная имитация ради этих сравнений не проводится; используются уже предусмотренные данные сетки.

Равенство или проигрыш сети сохраняются. Возможный вывод: для этой сетки простой табличный оцениватель достаточен. Результат выбора конфигурации при совместных требованиях сохраняет смысл и без превосходства нейросети.

Проверки этапа 2: соседи только из обучения; scaler не видит валидацию/тест; k выбирается без тестовых целей; одинаковые входы/кандидаты/пороги у всех оценивателей; ручной пример среднего соседей и разрешения равенств. Эти проверки ещё не являются выполненными тестами модели.
