# Рабочая статья R1.4: фиксированный частичный срез

Это новая редакция для проверки автора и оппонента, НЕ готовность к подаче. Предыдущий main.tex сохранён в истории 16fce069. Старый PDF перенесён без изменения байтов в article/legacy/pre_R14.pdf; это исторический результат, не статья R1.4. Новый PDF создаётся адресным workflow r14-paper.yml и передаётся в его артефакте. main, v2/ и журнал Perplexity не меняются.

## Содержание и сборка
Семь разделов по TASK: постановка и близкие работы; среда/параметры; протокол; частичный результат; будущие интерфейсы; самостоятельное концептуальное переразмещение; ограничения. Три векторные схемы, две таблицы; формулы и ссылки пронумерованы. RU/EN аннотации сохраняют одинаковые границы вывода. Авторы/аффилиации/согласия не назначены автоматически.

Научный срез намеренно заморожен: Actions45174257711, artifact14820151165, научный SHA b45bfee84d9b0727243faf6cd28eeda776813566. 131 запрос и одна main-серия не объявлены полной картой. Последующее продвижение карты в STATUS не подменяет этот срез без отдельного изменения статьи и проверки чисел. Все опытные величины синтетические.

После восстановления именно этого артефакта:
```
python scripts/build_r14_paper.py --checkpoint /absolute/path/to/checkpoint --out results/r14/paper-build
```
Без --checkpoint проверяется только перенос из сохранённого реестра, что отражается primary_archive_checked=false. С --checkpoint дополнительно проверяются первичные хеши/балансы и восстановление точечных метрик из целых тиков, но bootstrap НЕ пересчитывается и новая имитация НЕ выполняется. claim-index.json связывает 16 числовых команд фактического main.tex, исходный файл/поле/хеш, ячейку01 и место статьи. Параметры таблицы1 и ручного примера — исходные условия/ожидаемые ответы, не экспериментальные преимущества.

Прежний общий генератор не вызывается: он содержал неподдерживаемое журналом поле \misc. Новый библиографический файл использует поля сохранённого psta.cls, включая \URL, и обязательные разделители записей. Новый маршрут не запускает старые прогнозы/серии/графики и не перезаписывает их. Локально при разработке обнаружены и исправлены разделители библиографии и перенос длинной формулы; окончательная сборка запрещает переполнение строк и неопределённые ссылки. Успешная компиляция не равна научной приёмке.
