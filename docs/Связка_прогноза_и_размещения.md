# Связка разделов 5 и 6

Адаптер импортирует ядро непосредственно из v2/code, не копирует и не меняет его. MANIFEST v2 проверяется до и после. Контрольные EFE8мс, FFF4мс, EFF6мс и отказ при3мс должны совпасть точно.
Второй расчёт: используется сохранённая нейросеть results/demo_network.json из тетради02. В фиксированный момент начала тестового периода берутся Fog0 и Fog1 (зональные веса4 и2 заранее заданы). Признаки: текущее число ожидающих и занят ли сервер, прошлые наблюдаемые интенсивность/нагрузка; тип нового события стационарный, уже прошедшая Edge-задержка10мс — допущение.
Нейросеть обучена на Fog-событиях, поэтому второй расчёт использует два Fog — подмножество разрешённых E/F; неподтверждённый перенос обучения на другое Edge-оборудование не делается. В контрольном примере имеются E и F.
Фиксированный синтетический граф берётся из контрольного примера, но профили блоков одинаковы по55мс, A содержит две операции по27.5мс. Память каждого Fog4Мбайт; суммарно6Мбайт, поэтому все блоки на один узел не помещаются. Сообщения8000бит, каналы8Мбит/с — отдельные допущения, не вывод нейросети. Срок10с.
P и B получают один снимок с оценкой занятости (ожидающие +0.5*занят)*55мс. Оценка остатка половиной среднего — допущение. Реальный остаток ранее принятых задач из симулятора передан только исполнителю. Будущих новых поступлений во время короткого графа нет, память фоновых задач считается зарезервированной вне доступного бюджету4Мбайт. Это ограниченная демонстрация, не полноценная онлайн-миграция.
Прогноз total latency → to_ranks(mean_ms) → только порядковые команды P. Прогноз не заменяет физические профили блоков. Факт вычисляется replay на реализованных календарях. По одному примеру улучшение не устанавливается; P хуже B сохраняется.
