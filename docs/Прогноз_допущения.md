# Допущения прогнозной демонстрации

Отдельная синтетическая серия: 80 датчиков,4 Fog,8 Cloud,6000 событий,60/с,веса зон4:2:1:1,буфер50. Это не парковочная интенсивность400/ч. Цель — видимые различия очередей и проверка интерфейса, не калибровка под публикацию.
Шесть признаков доступны при поступлении в Fog: длина ожидающей очереди,занятость исполнителя,оценка offered load,EWMA интенсивности,тип датчика,уже прошедшее Edge+передача время. remaining_busy_ms и будущая истинная задержка не подаются нейросети. Границы train/calibration/test — временные60/80процентили поступлений; в train и calibration только завершившиеся до соответствующего cutoff задачи. Проверка условна на завершённых задачах; потери отдельно.
Naive/MA/EWMA обновляются только завершёнными к моменту запроса наблюдениями. MLP и scaler фиксированы после train. Верхний порог — point prediction плюс95процентиль ошибок на calibration, не строгая вероятностная гарантия. MAE считается для точечного mean_ms против задержки события, а не против недоступного истинного условного среднего.
M/M/1/K: K=buffer+1; lambda_eff учитывает блокирование, W=L/lambda_eff. Экспоненциальные предпосылки не совпадают с равномерным сервисом симулятора, поэтому это приблизительный baseline. p95 из ошибки на calibration, не точный квантиль M/M/1/K.
Первая серия показывает недопокрытие нейросетевого p95; оно сохраняется, постфактум порог по тесту не подстраивается.
